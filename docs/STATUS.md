## 证据不能外推的地方

- 普通主机 C 测试验证状态机逻辑，不验证 ARM ABI、相机调度或缓存效果。
- Unicorn 原厂机器码测试进一步执行真实指令，但内核、OSAL、文件、熵源、DMA/MMIO、硬件 VFX 及部分 model/通知服务是替身。
- 菜单资格／任务构造不等于真实屏幕可选、取消／删除 UI 完整可达或保存正确。
- 发布确认、版本／令牌正确不等于真实 LUT 像素正确，更不等于完整 JPEG/HEIF 成片成功。
- 文件级逆修改不等于真机恢复或救砖能力。
- 别的 FL2/FL3 或 macOS 工具的实机结果不属于这个照片 LUT 候选。

## 主要阻碍

1. 完整 UI 按键／弹窗生产者到取消、删除后端的可达性，外围 model 记账与失败反馈。
2. 外部缓冲的所有权、释放时机和其他读者排查；已保护的函数入口不能证明整份固件不存在别的读者。
3. 永久缺失完成和 CP DMA 故障时，没有经过证明的硬件中止／恢复机制。保留隔离是当前行为，不是可用固件的最终恢复方案。
4. 导入／覆盖、照片／视频切换、MR、保存和重启后的设置行为。
5. 进程重启／WBI 与会话恢复、早期参数读取、真实栈余量和缓存／MMU 效果。
6. 兼容增大 AP 文件的新安装器、运行时同步、模块加载和恢复。旧固定窗口安装包不兼容；没有可用相机适配器。
7. 最后的受控硬件启动、预览／回放、真实全尺寸成片、颜色和性能检查。此阶段不在当前公开复现命令中。
